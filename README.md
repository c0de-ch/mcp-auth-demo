# mcp-auth-demo

**Work in progress.** MCP server + client examples demonstrating many different authentication
approaches — static API key, locally issued JWT, embedded OAuth 2.1 authorization server, Keycloak
as external authorization server (resource-server pattern, client credentials, OAuth proxy, token
introspection, token exchange), mutual TLS and an auth gateway — with a documentation page per
approach and a comparison of them all.

The implementation plan, approach catalog, repository layout and verification strategy are in
[`docs/plan.md`](docs/plan.md). This README will be replaced by the full guide once the examples land.
